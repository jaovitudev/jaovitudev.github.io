# jaovitudev.github.io

Repositório oficial da página pessoal e portfólio web de **jaovitudev**, publicado por meio do **GitHub Pages**.

- **Site no ar:** [https://github.io](https://github.io)
- **Perfil no GitHub:** [https://github.com/jaovitudev](https://github.com/jaovitudev)

---

### Objetivo do Repositório

Este repositório foi criado para hospedar a página inicial pública de **jaovitudev** na internet. Ele centraliza a apresentação do perfil, serve como ponto de contato direto e funciona como vitrine principal para projetos e códigos desenvolvidos.

---

### Benefícios e Utilidade

- **Visibilidade nos mecanismos de busca (SEO):** Estrutura configurada com metadados e verificação no Google Search Console para que o termo `jaovitudev` apareça nos resultados de pesquisa do Google.
- **Portfólio centralizado:** Reúne a identidade digital e os links oficiais em um único endereço acessível de qualquer dispositivo.
- **Hospedagem gratuita e contínua:** Publicado diretamente via GitHub Pages, garantindo disponibilidade sem necessidade de servidores externos.
- **Base escalável:** Permite expandir a página futuramente com novos projetos, estudos de caso e links de contato mantendo o mesmo domínio.

---

### Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e metadados para indexação.
- **CSS3:** Estilização responsiva e interface em tema escuro.
- **SVG:** Ícones vetoriais embutidos diretamente no código para carregamento rápido.
- **GitHub Pages:** Hospedagem e publicação automática a partir da branch principal.
